# 产品需求文档（PRD）

## 1. 产品定位

本产品是个人使用的A股ETF与个股辅助决策系统。它在每个交易日收盘后分析市场、申万行业、ETF、个股及用户持仓，形成次日条件式操作计划，并维护未来约20个交易日的中期趋势判断。

产品不承诺收益、不替用户下单，也不以大模型直接生成价格或交易信号。所有数值结论必须来自可追溯的结构化数据和确定性计算。

## 2. 用户与目标

- 账户规模：10万～20万元
- 已持仓：约7万元，具体标的由用户录入
- 目标：争取年化15%，不构成收益保证
- 最大组合回撤：15%
- 允许空仓：是
- ETF重点：医药、科创50
- 股票范围：主板、创业板、科创板、北交所
- 行业范围：全部申万一级行业，并下钻二级行业
- 决策节奏：每日盘后复盘，T+1人工执行；中期观察约20个交易日

## 3. 产品原则

1. T日收盘数据产生的信号最早在T+1执行。
2. 没有合格机会时输出观望或空仓。
3. 数据来源、更新时间、策略版本和建议快照必须可追溯。
4. 风控可以否决普通交易信号。
5. 不展示“必涨”“稳赚”等误导表达。
6. 模拟数据和真实数据必须显著区分。
7. 新闻与公告是非可信输入，不能影响系统指令或执行代码。

## 4. 核心场景

### 4.1 每日盘后复盘

用户打开总览即可看到市场状态、风险分、建议权益仓位、行业强弱、ETF/个股候选、持仓风险和相较前一交易日的变化。

### 4.2 行业机会发现

系统对全部申万一级行业做横截面百分位评分，每天最多展示3～5个合格行业，并对其二级行业和候选股票下钻。无合格行业时返回空列表。

### 4.3 条件式操作计划

每条建议包含动作、评分、置信度、建议金额、最大金额、触发条件、失效条件、退出条件、理由、风险、数据时间和策略版本。

### 4.4 组合风险管理

系统根据现金、持仓、市值、行业暴露、组合回撤和波动调整建议。ETF与个股的重叠行业暴露合并计算。

## 5. 评分模型

### 5.1 行业评分

| 维度 | 权重 |
|---|---:|
| 5日/20日相对强度 | 25% |
| 趋势 | 20% |
| 上涨家数与市场宽度 | 20% |
| 成交额变化 | 15% |
| 波动与回撤质量 | 10% |
| 估值与基本面 | 5% |
| 公告及事件风险 | 5% |

原始指标先转换为当日横截面百分位，再按权重合成。风险指标先反向处理。

### 5.2 个股评分

| 维度 | 权重 |
|---|---:|
| 所属行业强度 | 25% |
| 基本面质量 | 20% |
| 趋势与相对强弱 | 20% |
| 流动性 | 10% |
| 估值 | 10% |
| 行业内竞争地位 | 10% |
| 公告及事件风险 | 5% |

### 5.3 ETF评分

综合趋势、动量、波动率、最大回撤、成交额、规模、折溢价、跟踪质量、相对强弱及与现有持仓的相关性。

## 6. 风控规则

### 6.1 品种上限

- 单只ETF：`min(30000元, 账户净值20%, 风险模型上限)`
- 单只股票：`min(15000元, 账户净值8%, 风险模型上限)`
- 北交所及高波动品种进一步折减
- 个股合计不超过净值30%
- 同一行业ETF与股票合计原则上不超过净值30%

### 6.2 回撤阶梯

| 组合回撤 | 风险动作 |
|---|---|
| 0%～5% | 正常运行 |
| 5%～8% | 停止激进加仓 |
| 8%～10% | 权益仓位不超过60% |
| 10%～12% | 权益仓位不超过30% |
| 12%～15% | 原则上清仓或仅保留低风险仓位 |
| ≥15% | 暂停新增交易并复核策略 |

## 7. 默认排除

- ST、*ST、退市风险、停牌、上市不足一年
- 流动性长期不足或数据不完整
- 连续涨停导致正常条件下不可成交
- 重大违规、调查、减持或业绩风险
- 买入后突破品种或行业暴露上限
- ETF规模、成交额、跟踪质量或折溢价不满足阈值

所有阈值从策略配置读取，不在业务逻辑中散落魔法数字。

## 8. 页面范围

1. 总览：市场状态、资产风险、行业、候选和数据时间
2. 行业：全部一级行业排名和重点行业详情
3. 推荐：ETF/股票条件式计划和执行状态
4. 持仓：手工录入、盈亏、集中度与行业暴露
5. 报告：盘后报告与历史日期
6. 回测：MVP演示验证；真实回测在后续阶段接入
7. 设置：风险、阈值、白名单、数据源和成本参数

## 9. MVP验收

- Mock模式无需密钥即可运行，页面显著标记演示数据
- 31个申万一级行业均可查看
- 每日最多展示5个合格行业，每行业最多一只股票
- ETF和股票建议均受金额、比例、回撤和行业暴露限制
- 支持持仓CRUD和盘后报告生成
- 所有建议带数据时间、来源和策略版本
- 核心评分与风控有自动化测试

## 10. 非目标

- 不连接券商或自动交易
- 不提供收益保证
- MVP不声称拥有完整实时行情
- MVP回测仅验证管线，不作为策略有效性的证据
